Bituo Dial · BLE 电表网关

固件 1.1.4 · 2026-09-24 · 完整版见同目录 Markdown
配套 HA：bo706/BituoPMD v1.1.3+（改 HA，不改本固件）

1. 产品定位

SPM / SDM 在 BLE 模式下只发加密广播。Dial 做成独立网关：南向解密最多 16 块表，圆屏显示，北向经 2.4 GHz Wi-Fi 用 MQTT 上报。电表不必改配 Wi-Fi。匹配只靠 12 位 SN + 32 hex 广播密钥，禁止按蓝牙 MAC（地址会变）。

与 EW 电表（表自带 Wi-Fi、扁平 GET /data）不是同一条线。官方 BituoPMD 只认 EW；Dial 必须用 fork。

电表 BLE 广播 ──► Dial（解密 / 圆屏）──► MQTT Broker ──► Home Assistant
                                      └─ 可选局域网网页（出厂关，共存时常打不开）

2. 规格摘要

硬件ESP32-S3 rev v0.2，8MB Flash / 无 PSRAM；GC9A01 圆屏；USB 口为下、橙色三角为上
软件ESP-IDF 5.2.3，LVGL 8.3，NimBLE 被动扫描 25% 占空比 + Wi-Fi 时隙
容量最多 16 表；概览最多 8 行滚动
MQTT约 10 s；data / summary / mdata Retain；keepalive 30 s
在线≤15 s 白；15～90 s 黄；>90 s 灰 + 蜂鸣两声
Wi-Fi仅 2.4 GHz。保存凭据后 STA-only（GOT_IP 关 SoftAP）。无凭据或掉线约 60 s：热点 BitUo-Dial-XXXXXX / 12345678 / 192.168.4.1
HTTP出厂关。打开后 http://<IP>/。BLE 共存时电脑/HA 常访问失败，不能当日常主路径
USB烧录用。当网关运行请拔掉电脑 USB，否则会复位并干扰 Wi-Fi

量测：U = 编码÷10（V），I = ÷100（A），P = 有符号÷1000（kW），E = ÷100（kWh）。广播无 PF，界面固定 PF --。开路时 I/P/E 为 0，与 App 一致。

3. 圆屏

短按：概览 → 详情 → 系统。系统页长按进 Setup（扫 Wi-Fi、加/删表、LAN web、热点）。保存 Wi-Fi 后应显示绿色 SSID 与 STA IP，不应停在黄色 SoftAP。

MQTT 绿 = 已连 Broker；黄 (wait) = 未连上，可能闪一下后自动回来。

4. 怎么用

  1. USB 供电 → 系统页确认 v1.1.4。
  2. Setup 连 2.4 GHz Wi-Fi，看绿色 IP。
  3. Add meter：SN + bcast_key。不要给这些表重新配电表 Wi-Fi。
  4. 配 MQTT，Broker 与 HA 相同；系统页 MQTT 变绿。
  5. 调试网页：打开 LAN web。HA 日常不依赖网页。

MQTT Topic（Client ID = Dial SN，如 DIAL-0180B4）

Topic说明
bituo-dial/{DialSN}/meters/{MeterSN}/data单表，功率 W，Retain
…/summary在线表数与功率，Retain
…/mdata名单与显示名，Retain
…/cmd → …/cdata远程命令 / 应答

Home Assistant：HACS 自定义仓库 bo706/BituoPMD，装 v1.1.3+（选带 v 的版本号，不要选长串 commit）→ 重启 HA。HA 须已接同一 MQTT。首次可用 IP 探测一次 /data（需 LAN web）。之后走 MQTT。Dial 增删表后重载该集成。不要对 Dial 条目用定位灯 / 恢复出厂 / URL-OTA。

OTA：网页上传 bituo-dial.bin。USB 只写 app，不要 erase_flash。

5. 接口与单位

GATT / HTTP / MQTT 共用命令信封 {"ok","msg","event","d"}。常用：get_info、add_meter、list_meters、set_mqtt、setwifi。

通道功率
圆屏 / GET /api/meterskW
MQTT data、GET /dataW（内部 ×1000）
HA BituoPMD 1.1.3+W（不再 ×1000）

6. 明确不做 / 限制

  • 无设备 HTTPS、无 URL-OTA、无继电器 / 清零 / 恢复出厂。
  • 不从广播编造 PF；不按 MAC 认表。
  • 不用官方 PMD 加 Dial。
  • 5 GHz 连不上；满 16 表堆较小；插 USB-JTAG 会打断网关。
验收：圆屏有数 → MQTT 绿 → Broker 上 bituo-dial/{DialSN}/meters/+/data 约 10 s 更新 → HA 电压/功率变化。
不要只凭浏览器打不开 Dial 网页判失败。

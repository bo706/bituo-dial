## 2. 硬件 / 真机事实（全部实测，勿改）

- 模块：**ESP32-S3 rev v0.2 + 8MB XMC 嵌入式 Flash、无 PSRAM**（sdkconfig 为 `# CONFIG_SPIRAM is not set`，真机日志亦报 PSRAM unavailable 回退内部 RAM；任务书"有PSRAM/16MB"是错的。内存分配用内部 DMA RAM，失败有 INTERNAL 回退）。
- 串口：**COM7**，USB-Serial/JTAG；蓝牙 MAC `ac:a7:04:01:80:b4/b6`。
- 电源保持：**GPIO46 必须在 app_main 第一行置高自锁**，否则约 100ms 断电（已实现，勿删）。
- 屏幕 GC9A01 240×240 圆屏，SPI2_HOST 40MHz mode0，RGB565(COLMOD 0x05)、INVON、`CONFIG_LV_COLOR_16_SWAP=y`：
  - **MOSI=5、SCK=6、CS=7、DC=4、RST=8、BL=9**（任务书把 MOSI/SCK 写反，以此为准）。
- 旋转编码器（正交，内部上拉、按下接地低有效）：**A=40、B=41、按键=42**；静止 A=B=BTN=1，每格 detent 输出 delta=±1。蜂鸣器 **GPIO3**（PWM/LEDC）。
- 真实电表（NVS 中唯一 index0）：SN=`C85024E851F1`，型号 `SDM01_3PN`（三相），label=`SDM01-test`，broadcast_key=`<redacted-broadcast-key>`（旧 key 已失效），PIN=`<redacted>`。**BLE 地址是 RPA 随机私有地址、会变，严禁按 MAC 匹配电表，必须按 key 盲解、CCM Tag 过即命中。**

## 4. 协议核心事实（解密/解析，别再重新推导）

- 26B 长包：`[0-1]=FF FF`；`[2]=ctrl`；`[3-6]=counter 小端u32`；`[7-21]=15B密文`；`[22-25]=4B Tag`。Windows bleak 常剥成 24B（去掉 FF FF），固件已有 24B 防御分支。
- ctrl：`bit7=GATT已装 | bit6-4=编码版本(当前1) | bit3-2=相位(三相0=A/1=B/2=C，按帧轮换) | bit1-0=类别(3=三相)`。
- CCM：key=broadcast_key(16B)，**nonce_12 = 8×0x00 ‖ BE32(counter)**（counter 空中是小端、nonce 要大端，**手工逐字节移位，严禁 memcpy/htonl 偷懒**），无 AAD，Tag 4B。
- 15B 明文（§9.3.1，全小端）：`[0:2]u16/10=电压V`；`[2:4]u16/100=电流A`；`[4:7]int24有符号/1000=有功P 单位kW(可负,需符号扩展)`；`[7:11]u32/100=正向电能kWh`；`[11:15]u32/100=反向电能kWh`。
  - **广播里没有功率因数 PF**，UI 固定显示 `PF --`，禁止臆造；PF 走 GATT 读特征（后续阶段）。
  - 每帧只带一相：先 `xQueuePeek` 上一帧合并快照做基底、只刷新本相，禁止整帧清零；`total_active_power=三相之和(kW)`。
- 解析正确性离线证据：`tools/plain15_selftest.py`（Python313 运行，全 PASS，含负功率/满量程 roundtrip）。

## 7. 已验证死路 / 坑（禁止重复尝试）

1. 按固定 MAC 匹配电表——RPA 必变，永远落空（已改 key 盲解）。
2. NimBLE host 回调里 vTaskDelay 分片——会卡死 host。
3. 512B 响应缓冲装 16 表——已扩到 4096B（BITUO_RESP_CAP）。
4. 让用户取消手机配对——会清 LTK、打回只发短包。
5. 任务书三处错：PSRAM/16MB（实无PSRAM/8MB）、MOSI/SCK 引脚反（以§2为准）。
6. **FreeRTOS HZ 必须 1000**（已锁 sdkconfig）：100Hz 时 `pdMS_TO_TICKS(5)=0`→vTaskDelay(0) 饿死 Core1 的 IDLE→task_wdt；循环延时用 `wait=pdMS_TO_TICKS(5); vTaskDelay(wait>0?wait:1)`。WDT 超时10s、未开 PANIC（只打印不复位）。NimBLE/BT_CTRL pin Core0，ui_task pin Core1。
7. Nonce 大小端、int24 负功率符号扩展、功率单位是 kW 不是 W——见 §4。
8. 屏幕方向已定值 MADCTL `0x88`；禁止改回 0x08/0xC8，见 §5-B。
